What this live page is — and isn’t

This is a read-only public view of the project’s ThingSpeak channel. It shows the newest entries and applies the same threshold review rules as the local AI service, computed in a serverless function.

The full system — SQLite persistence, symptom journal, the ThingSpeak bridge and the Python Isolation Forest service — runs locally on the project machine. This page has no database and no write access.

Research prototype only. This device does not diagnose arrhythmias or replace clinical assessment. MAX30102 does not provide an ECG. Seek urgent medical care for severe or emergency symptoms; do not wait for this dashboard.
